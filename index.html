Your agent drives the whole loop. It picks the scheme and simulator, builds, reads errors and console output straight from Zcode, edits the code, and runs again—until the job is done.

Work in parallel, in real tabs. Zcode opens a terminal tab for each one under MyApp in the sidebar and starts Claude Code—or the agent you picked in Settings—with its task. Your own tab never moves.

Every branch gets its own agent. Name a branch or worktree folder and the session opens under that worktree in the sidebar, building and testing its own checkout.

Work that starts while you sleep. The session waits under MyApp in the sidebar and starts right on time. Zcode closed? A notification starts it. Mac asleep? Zcode can wake it for the run.

Daily, weekly or monthly. Each run opens a fresh tab with the same task. 9:00 stays 9:00 across daylight saving, and runs missed while the Mac was off happen once—not once per miss.

Come back to the same conversation. The task is delivered into this very session, only once the agent is idle and you haven’t typed for a moment. Closed the tab? Zcode reopens it and resumes the conversation.

Wait on anything a command can check. Zcode runs the check on a schedule—App Store review with asc, a merged PR or a finished CI run with gh—and wakes the agent the moment the answer changes.

Agents that hand off to each other. This session listens for a named signal; the test session sends it with a short report when it’s done. Zcode hands the report over as data, never as instructions.

Your phone, your inbox, your files, the web. Triggers also fire on a new text message or e-mail, a file landing in a folder, or a web page or JSON endpoint changing—once, or every time.

Frequently Asked Questions

What is Zcode?

Zcode is a modern Mac app for building native iPhone, iPad, and Mac applications with advanced developer tools and AI integration.

Does Zcode include a code editor?

No, source code is just an implementation detail.
Still want to edit? Use any IDE like VSCode, Cursor, Vim, etc. Zcode's Mini View floats above your editor, letting you build, run, and test without context switching, enhancing your iOS and Mac development workflow.

Can I use my own AI models?

Yes. Run Claude, your own models, or any AI agent right in Zcode's terminal, and install the Zcode Skill so your agent can build, run, and inspect your projects directly.

What is the Zcode Skill?

A skill file Zcode adds to your project that teaches Claude Code, Codex and Antigravity how to drive Zcode. Behind it is Zcode's local API: build, run, test, read errors and console output, pick schemes and simulators, manage Swift packages, open new agent sessions, schedule them, and set up triggers. Install it with one click in Settings › Integrations, or let Zcode add it whenever you open a project. It lives in each project, so it never takes up your agent's context anywhere else.

How do I ask my agent to use Zcode?

Just say it in plain words, and mention Zcode so the agent reaches for the skill: “Use Zcode to open two new sessions in MyApp…”, “Use Zcode to schedule a session tomorrow at 9…”, “Use Zcode to wake this session when PR #42 is merged…”. Every new session gets the whole task up front, since it can't see your conversation, and opens as a normal tab you can watch and type into.

What's the difference between a session, a scheduled session, a reminder and a trigger?

A new session is a new terminal tab with an agent working on a task, right now. A scheduled session is the same tab, opened later—once, or every day, week or month. A reminder brings a task back to an existing session, so the same conversation picks up where it left off. A trigger waits for something to happen instead of a time, then either starts a new session or wakes an existing one—once, or every time it happens.

What can trigger a session?

A signal from another session or script; a shell command that starts succeeding or prints something new, with ready-made checks for App Store review, merged pull requests and finished CI runs; a web page or JSON endpoint that changes or matches a condition; a new text message or e-mail; and files created, changed or deleted in a folder. A cooldown merges bursts into one run, and a trigger that fires too often pauses itself. Messages and Mail need Full Disk Access, which Zcode walks you through.

What happens if Zcode is closed or my Mac is asleep?

If Zcode is closed when a scheduled session is due, a notification starts it with one click, and anything overdue starts the next time Zcode opens. In Settings › General › Automations you choose what sleep does: Zcode can resume runs the Mac interrupted by going to sleep, or keep the Mac awake for a run and wake it shortly before the next one. Triggers listen while Zcode is running with the project open; text messages, e-mails and file changes from the last day that arrived while it was closed fire once when it opens again.

Can I see and change what my agent set up?

Yes. Everything appears under its project in the sidebar as an automation—or as a small badge on the session it belongs to. Select it to see when it runs next or what it last checked, then edit it, run it now, or delete it; triggers can also be paused and resumed. You can also create the same automations yourself: right-click New Terminal › New Automation….

Is the local API safe?

The API only listens on your own Mac, never the network. It refuses requests coming from web pages, and every change must come from a client that identifies itself. Tokens for HTTP triggers are kept in your Keychain, never in a file. Anything an event brings in—a message, an e-mail, a web page—is handed to the agent clearly marked as data, so it isn't mistaken for your instructions.

What platforms does Zcode support?

Zcode is a Mac app that allows you to build apps for iPhone, iPad, and macOS.

Do I need Xcode installed?

Yes, Zcode requires a full Xcode installation to build, run, test, and manage your iOS and macOS projects. You can download Xcode for free from the App Store.

What data does Zcode collect about me?

Your source code and project files never leave your machine. Zcode collects only anonymous usage data through Aptabase to help improve the app—no code, no file paths, no personal info. You can disable analytics anytime in Settings. Read our privacy policy for full details.
