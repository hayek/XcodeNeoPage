Changelog

What's new in every version of Zcode. The app shows the changes since your version when an update is ready.

0.52.0 November 26, 2026

Fixed

  • Check for Updates no longer fails with "GitHub is temporarily limiting update checks from your network" when other apps on your network have used up GitHub's hourly limit.

0.51.0 November 26, 2026

New

  • Settings ▸ Integrations now offers --remote-control for Google Antigravity, and Claude Code gets --remote-control, --chrome and Accept edits / Auto / Plan permission modes, all off until you turn them on. Antigravity tabs now always resume their conversation, so its Resume previous session switch is gone, and agent options wrap onto a second line instead of running off the window.

0.50.0 November 25, 2026

Fixed

  • Dragging an idle Claude Code session onto another worktree now moves it. Before, the worktree lit up but nothing happened; the right-click Move to Worktree menu was the only way.

0.49.0 November 25, 2026

Fixed

  • Every Codex session now resumes its own conversation when Zcode reopens it, and is named after it, instead of all but the most recent one opening Codex's session picker. Codex asks you once to trust the hooks Zcode adds for this; until you do, sessions resume as before.

0.48.0 November 25, 2026

Improved

  • A reminder or trigger that continues an Antigravity (agy) session now resumes that session's own conversation with the task, instead of starting a new one.
  • Antigravity (agy) sessions in the sidebar are now named after their conversation's title, like Claude Code sessions, instead of "Terminal 7".

Fixed

  • Every Antigravity (agy) session now resumes its own conversation when Zcode reopens it, instead of only the most recent one picking up where it left off and the others starting over.

0.47.0 November 25, 2026

New

  • Move an idle Claude Code session to another worktree of the same repo: drag its tab onto the worktree, or right-click the tab ▸ Move to Worktree. Claude continues the same conversation in the new folder, the tab's reminders and triggers go with it, and when you quit Claude the terminal follows to the new folder too.
  • The update window now shows what's new: every change since the version you're on, newest first. The full list is at zcodeapp.com/changelog.html.

Improved

  • The Zcode skill now reaches Codex and Antigravity too: when either is enabled or installed, Zcode also writes it to .agents/skills/zcode.

0.46.1 November 25, 2026

Fixed

  • Check for Updates now explains when GitHub is temporarily limiting update checks from your network, and when to try again, instead of showing "Invalid HTTP response (403)".

0.46.0 November 25, 2026

New

  • Use several terminal agents side by side: enable any number in Settings ▸ Integrations, then right-click New Terminal to start a session in Claude Code, Codex, Antigravity, OpenCode, Cursor, your custom command or a plain terminal. Each project remembers its last pick, which Cmd+T opens.

0.45.0 November 24, 2026

New

  • Right-click a session in the sidebar to Mark as Unread or Mark as Read.

Fixed

  • Terminal fixes: held letter keys repeat, wide characters show correctly while you compose input, terminal modes survive a font change, and a few rare crashes are gone.

0.44.0 November 19, 2026

New

  • Antigravity: choose Accept edits, Auto or Plan mode in Settings. Zcode now knows when an Antigravity session is working or idle, so reminders and triggers can deliver into it and a finished turn badges its tab.

Improved

  • Codex options match codex-cli 0.158: YOLO uses the current flag, and a new Auto-review option is available.

Fixed

  • Quitting an Antigravity or Cursor agent no longer posts a "command finished" notification.

0.43.0 November 19, 2026

New

  • Choose what runs Zcode starts on its own do when your Mac sleeps, in Settings ▸ General ▸ Automations: continue a run that sleep interrupted once the Mac wakes (the default), or wake the Mac shortly before a scheduled run and keep it awake until the run ends.

Improved

  • Scheduled sessions and triggers are now one Automations feature: selectable sidebar rows with a detail view, one edit sheet with an explicit Save, a shared context menu (Edit, Run Now, Pause/Resume, Delete) and an Automations section in Sessions.

0.42.0 November 18, 2026

Improved

  • Scheduled sessions and triggers in the sidebar get a hover card showing when they run next or what they watch, their status, and the start of their task.

0.41.0 November 18, 2026

Improved

  • A terminal tab's hover card lists its reminders and triggers, with their next run and status.

0.40.0 November 17, 2026

Improved

  • Triggers can check as often or as rarely as you like: Check every takes any number of minutes, hours or days, up to 365 days.
  • The trigger sheet shows when a trigger last checked and when it will check next.
  • If a trigger's check fails (say the Mac just woke and isn't online yet), Zcode tries again within minutes instead of waiting the whole interval.

0.39.0 November 17, 2026

New

  • Triggers: start an agent session, or continue one, when something happens, not just at a set time. A trigger can listen for a signal from another session or a local script, a command's result (like an App Store review finishing), a web page or JSON API value changing, a new SMS/iMessage or email, or a file appearing in a folder, and can fire once or keep listening until you pause it.
  • Create a trigger from New Terminal ▸ New Trigger…, or let your agent set it up through the Zcode API. Messages and Mail triggers need Full Disk Access.

Improved

  • Zcode is about 30% smaller.

0.38.0 November 17, 2026

Improved

  • Clicking a Zcode notification about a terminal session opens that session's tab (reopening it if it was closed), instead of only bringing Zcode forward.

0.37.0 November 15, 2026

New

  • Agents can close terminal tabs through the Zcode API, so a session an agent opened can be cleaned up when its work is done. A closed tab stays in the project's session history, and a tab you're typing in is never closed out from under you.

0.36.0 November 10, 2026

New

  • New Project creates Xcode 27.2's JSON project format (project.xcproj), matching what Xcode itself generates, and adds a Command Line Tool template.

Improved

  • Projects created by Xcode 27.2 open, build and run in Zcode, including version and build-number editing.

Fixed

  • Building a visionOS-only project works when no visionOS simulator is installed.

0.35.0 November 5, 2026

New

  • Right-click a terminal tab in the sidebar to copy its name.

0.34.0 November 5, 2026

New

  • Agents can start or schedule a session in a specific worktree by naming its branch or folder (the new worktree option of the Zcode API); the Zcode Skill explains it. Naming a worktree you hid from the sidebar shows it again.

0.33.0 November 5, 2026

New

  • Right-click a worktree in the sidebar to copy its name or its branch name.

0.32.0 November 5, 2026

New

  • Worktrees in the sidebar: a project with several git worktrees lists each one as its own row, with its branch, folder, Run button and its own terminal tabs, and each can be collapsed on its own. Worktrees an agent creates appear automatically.

Fixed

  • Switching to another project no longer resets a project's worktree back to the main checkout; clicking the project returns to the worktree you were using.
  • A worktree you remove from the list now stays removed instead of coming back on the next git activity. Bring it back with the project's Show Hidden Worktrees menu.

0.31.0 November 3, 2026

New

  • Reminders on terminal tabs: right-click a tab to send its agent a task once, daily, weekly or monthly, continuing that conversation when the agent is free or starting a new session. Reminders notify you even while Zcode is closed, never run twice, and keep their time of day across daylight-saving and time-zone changes.

Improved

  • Scheduled sessions are listed at the top of the project's Sessions tab, with Run Now and Delete in their context menu.

0.30.0 November 3, 2026

New

  • Agents can open new sessions: ask an AI session to "do this in a new tab called fix" or "start 3 sessions to review this", and the tabs appear in your project.
  • Scheduled sessions: right-click New Terminal ▸ Schedule Session… to start an agent session at a set date and time. If Zcode is closed, a notification brings it back and starts the session.

Improved

  • Restored tabs resume the agent and conversation they last ran.
  • The local API now only accepts connections from your own Mac and refuses requests from web browsers.

0.29.0 November 2, 2026

Improved

  • Updated terminal engine: faster search, selection and link detection in long wrapped output, Terminal.app-style smart selection, and safer link opening (scripts and apps are never launched from a clicked link, and custom link types ask first).

0.28.0 October 27, 2026

Improved

  • Updated terminal engine; Option+←/→ word jumps are now handled by the terminal itself.

0.27.0 October 18, 2026

Fixed

0.26.0 October 15, 2026

Improved

  • The hover card's terminal preview wraps long lines and shows more of the screen, so an agent's recap is readable.

New

0.24.0 October 11, 2026

Maintenance release with no user-visible changes.

0.23.0 October 11, 2026

Improved

New

  • See Claude subagents in the sidebar: terminal rows running Claude Code show a badge counting the subagents the session is running, with no hooks needed.
  • Session info card: hover a sidebar session for a moment to see its full title, status, directory, program, running commands, subagents and session ID.

0.21.0 October 11, 2026

Improved

Fixed

0.20.0 October 11, 2026

New

  • See what each terminal is running: sidebar terminal rows show the program in the foreground (claude, xcodebuild, npm, nvim…) and a badge counting the commands running alongside it, such as Claude Code's tool shells and background jobs. Hover the badge to see the commands.

0.19.0 October 11, 2026

New

  • Agent notifications from any CLI: notifications that agents send through the terminal (iTerm2, kitty and Ghostty styles) become macOS notifications and tab badges, not just Claude Code's. The "command finished" notification for commands that run 5 seconds or more now fires (editors, ssh and agent CLIs are skipped).
  • Status and progress in the sidebar: terminal tabs show a progress ring while a program reports progress, and an orange "needs you", red "failed" or green "done" mark when a program reports its status.
  • Jump between prompts: Cmd+↑ / Cmd+↓ scroll to the previous / next shell prompt in new terminal tabs.

Improved

  • Faster terminal engine: scrolling and typing stay smooth while agents stream a lot of output.
  • Find bar counter: terminal search shows the current match and the total, e.g. "2/14".
  • Light/dark follows Zcode: programs like Neovim re-theme when the terminal palette switches.

Fixed

  • Closing a tab ends its shell cleanly (history saved, jobs hung up), and dropped files paste as text.
  • Option+←/→ move by word and Shift+Enter inserts a newline in Claude Code; the scroll bar follows the system "Show scroll bars" setting.
  • Cmd-hold badges and Cmd+click line up correctly on lines with emoji or CJK text.

0.18.0 October 4, 2026

Fixed

  • Links open correctly from Claude Code output: Cmd-clicking a link (or using its Cmd-hold badge) no longer drags the following words into the URL, so a link followed by text such as "(private until you share it…)" no longer opens as a broken address.

0.17.0 October 3, 2026

Improved

  • Clickable wrapped paths: file paths that Claude Code and other agent CLIs wrap onto the next line in the terminal are recognized as one path. Cmd-hold badges, Cmd+click to open and Cmd+Option+click to copy all work from either half, so you no longer need to widen the window to open them.

0.16.0 October 2, 2026

New

  • jj (Jujutsu) support: Zcode understands jj repos alongside git. The toolbar shows the current bookmark or change ID, the Changes tab lists jj changes and diffs, and jj workspaces are grouped in the sidebar like git worktrees. New workspaces appear automatically.

Improved

  • Hands-off in jj repos: version control stays with your agent. Git actions (commit, push, pull, stash, branch switching) are hidden for jj repos, and the Zcode skill tells the agent to use jj.
  • Clean jj history: Zcode's own skill and hook files are kept out of jj changes.

0.15.0 October 2, 2026

New

  • Sessions history: a new Sessions tab in the console lists every terminal session a project has had, with last-used times. Reopen or swipe to delete any of them.
  • Idle cleanup: sidebar sessions left unused for a while (2 days by default) now close automatically.

Fixed

  • Devices that are paired or connected after a project loads now appear in the destination picker.

0.9.0 September 15, 2026

0.7.0 August 24, 2026

Fixed

  • Selections survive streaming output. A selection you drag out while an agent redraws a spinner now stays put so you can copy it.

0.6.0 August 19, 2026

Improved

0.5.0 August 4, 2026

New

  • Choose the terminal cursor's shape (block, underline or bar) and whether it blinks, in Settings ▸ Appearance. Programs that set their own cursor, like Neovim, still can.

Fixed

  • Terminal tabs and agent sessions survive a crash or force quit instead of being lost.
  • Clicking an unfocused terminal focuses it again.
  • Zcode no longer slows down and uses a full CPU core after running for hours while an app or a build streams output.
  • Git worktrees stay grouped correctly after a relaunch, in projects that live in a subfolder of the repo, and when git can't be reached.
  • A lid-closed Prevent Sleep session is no longer cut short when its background helper restarts.

0.4.0 July 26, 2026

Improved

  • Terminal rendering now runs on the GPU, cutting CPU use during heavy output.
  • The terminal cursor no longer blinks.

0.3.6 July 18, 2026

Improved

  • Product ▸ Prevent Sleep has a clearer layout: Caffeinate ▸ picks how long to stay awake (Off, Indefinitely, or 15 minutes to 2 hours), and Caffeinate with Lid Closed is a checkbox that keeps the Mac running with the lid shut for the same duration.
  • Quitting Zcode now turns Prevent Sleep off in every mode, and the lid-closed helper is more robust: clean shutdown, crash recovery, and it updates itself with the app.

Fixed

  • Installed terminal agents are detected more reliably, and resuming a previous agent session works for tabs that changed directory or predate agent tracking.

0.3.5 July 13, 2026

New

  • Product ▸ Prevent Sleep has three modes, so a long build, test run or archive can outlast your Mac's sleep timer: Off, Caffeinate (keeps the Mac awake while the lid is open, also on battery) and Caffeinate with Lid Closed (keeps it running with the lid shut, for 15 minutes up to 2 hours).
  • Lid-closed mode uses a small background helper that you approve once in System Settings ▸ General ▸ Login Items & Extensions. It is always time-boxed and the helper owns the deadline, so normal sleep returns when the timer ends, when you quit Zcode, and even after a crash or restart. A closed Mac that keeps running has less airflow: keep it plugged in and on a hard surface, not in a bag.
  • New Help ▸ FAQ entries explain Prevent Sleep.

0.3.2 July 12, 2026

Maintenance release with no user-visible changes.

0.3.1 July 12, 2026

0.3.0 July 12, 2026

Improved

  • Builds and tests that an agent starts through the local API no longer post notifications, so agent-run builds stay quiet.
  • Updated terminal engine with rendering, scrolling and memory-leak fixes.

Fixed

  • Build tasks no longer wait for the launch grace period before completing.
  • Running on an iOS Simulator installs the correct simulator build.
  • Booted simulators are no longer mistaken for physical devices with Xcode 26.
  • Switching schemes through the local API reloads destinations, as it does in the app.

0.2.0 June 5, 2026

New

  • Product ▸ Prevent Sleep keeps your Mac awake during long builds.
  • Git worktrees of one repository are grouped into a single sidebar row, and switching to a branch that another worktree has checked out takes you to that worktree.
  • The Zcode Skill: Zcode installs a skill that teaches Claude Code to build, run and test through Zcode's local API (replacing the MCP server), and a skill marketplace powered by skills.sh lets you browse and install more.
  • When a Claude Code session finishes, its terminal tab gets a badge and you get a notification; the Dock icon counts the tabs waiting for you.
  • Run apps on physical iOS devices.

Improved

  • A new project opens with a terminal tab ready, the tab menu adds Close Other Tabs, and Zcode offers to install the Metal Toolchain when a build needs it.

0.1.0 March 25, 2026

New

  • First public beta of Zcode: open your Xcode projects in a simple, Xcode-like window, pick a scheme and a destination, and build, run and test on simulators and your Mac.
  • Every build and test run lands in a timeline with structured, searchable console logs, its issues and a one-click replay.
  • A built-in terminal with tabs for each project, color themes, and optional auto-launch of Claude Code or another agent CLI that resumes its previous session.
  • Source control in the app: review changes and diffs, stage files, commit with a message suggested by Apple Intelligence, and switch branches.
  • Create new projects from iOS, macOS and command-line templates, and manage Swift package dependencies.
  • AI agents can build, run and test your project through Zcode's built-in MCP server.
